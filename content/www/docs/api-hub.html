API do hub

Serviço único FastAPI (stacks/.celeros-hub/api/app.py — um arquivo, ~850 linhas). Leitura é pública por design; escrita exige Authorization: Bearer com escopo. Os botões ▶ testar abaixo executam de verdade contra o hub que está servindo esta página — só endpoints GET públicos.

público escopo apps escopo updates JSON em tudo (404 incluso)

Saúde & estado #

RotaRetorna
/healthGET {"status":"ok","version":"0.6.0"} — usado pelo healthcheck do deploy
/api/infoGET service, versão, base_url, uptime, firmware.api_level, boards, contagens da loja, downloads por app + total, canais OTA (versão/api_version/variant/hasFirmware/updated) — o "everything" do monitoramento
/api/docs · /api/openapi.jsonGET Swagger — só existe com HUB_DOCS=1 (desligado em produção) off

Loja #

RotaRetorna
/store/index.jsonGET índice: {name, base, updated, categories:{nome→url}} com atalho "Todos"
/store/all.jsonGET união das categorias: {category:"Todos", updated, apps:{pkg→entry}}
/store/<slug>.jsonGET categoria única (slug do nome); all aqui → 409 apontando o caminho certo
/store/apps/<pkg>/main.jsGET o app com text/javascript + no-cache; conta download
/store/apps/<pkg>/…GET estático: app.json, icon.png, extras multi-arquivo

OTA #

RotaRetorna
/updates/<canal>/update.jsonGET manifest do canal (no-cache)
/updates/<canal>/firmware.binGET binário quando o canal tem (servido estático)

RotaRetorna
/help/index.jsonGET {categories:[{name,url}]}
/help/categories/<slug>.jsonGET {articles:[{title,url}]}
/help/articles/<slug>.jsonGET {content:"…"} — texto puro sem acentos

Admin — publicar & remover #

Tudo aqui exige Bearer com escopo; sem nenhum token configurado o /admin inteiro responde 503.

RotaEscopoCorpo / efeito
/admin/whoamiGETqualquer token {"name","scopes"} — confere token do CI sem risco
/admin/appsPOSTapps multipart file (zip do pacote) + form force. Valida app.json, limites, dono e anti-downgrade; grava atômico em store/apps/<pkg>; retorna md5/size + contagem da loja
/admin/apps/<pkg>DELETEapps remove o pacote (regra de dono; root sempre)
/admin/updates/<canal>POSTupdates multipart firmware (bin, opcional) + form update.json (string JSON) + force. Valida semver/api_version/variant, anti-rollback; grava bin por rename
/admin/updates/<canal>DELETEupdates remove o canal inteiro

Exemplo com o curl puro:

▸bash
# quem sou eu?
curl -s -H "Authorization: Bearer $TOKEN" https://os.celer.tec.br/admin/whoami

# publicar firmware no canal da CYD
curl -H "Authorization: Bearer $TOKEN_CI" \
     -F "firmware=@CelerOS.bin" \
     -F 'update.json={"version":"1.8.0","changelog":"- SD no CYD"}' \
     https://os.celer.tec.br/admin/updates/esp32

Erros #

StatusQuando
400metadado inválido (packageName/semver/api/canal), extensão fora da lista, colisão de nome no zip, .js grande com api baixa
403sem/expirado token, escopo insuficiente, dono do pacote diferente
409versão ≤ atual (app ou canal) sem force
413limites de tamanho (body, zip descomprimido, .js total, icon, assets)
42910 falhas de auth em 10 min do mesmo IP → bloqueio 15 min (Retry-After)
503nenhum token configurado no servidor (admin desligado)
i

Headers de segurança em tudo (nosniff, X-Frame-Options: DENY, no-referrer) e 404 sempre JSON — /api/* e /admin/* com {"detail":"nao encontrado"}. Os mounts de conteúdo (/store, /updates, /help) servem com no-cache para o device revalidar; /assets tem ETag normal.
