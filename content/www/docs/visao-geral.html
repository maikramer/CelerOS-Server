O ecossistema CelerOS

CelerOS é um sistema operacional GUI open-source (fork GPL-3.0 do KryonOS) para ESP32 com runtime de apps em JavaScript. O hub — este servidor, os.celer.tec.br — é a nuvem mínima que o ecossistema precisa: loja de apps, canais OTA, ajuda online e portal. Nada mais.

leitura pública escrita só com token um serviço FastAPI

As peças #

⛁

Firmware CelerOS

ESP32 (IDF) com launcher em immediate-mode sobre LovyanGFX, engine JS Duktape (ES5), OTA de slots A/B, WiFi/BLE, IA on-device e voz. Repo CelerOS — CELEROS_API_LEVEL vigente: 24.

☁

Hub (este servidor)

Um serviço FastAPI único: catálogo da loja gerado na rota (o disco é a verdade), canais OTA por placa, ajuda online e portal. Leitura pública, escrita com token + escopo.

‣

celerctl

Ferramenta USB estilo adb em Python: shell, push/pull de arquivos, screencap (dump do framebuffer), tap/swipe, install de apps e gravação OTA sem esptool.

◫

App Store no device

App de sistema em JS que lê o catálogo do hub, baixa com MD5 por arquivo e instala com rename atômico — inclusive o self-update dela mesma.

Princípios de projeto #

  • O disco é a fonte da verdade. O catálogo da loja não é um banco: as rotas /store/*.json escaneiam content/store/apps/ a cada request. Publicar = gravar arquivo. Remover = apagar pasta.
  • Nada de URL de produção em arquivo. As URLs absolutas do catálogo e do OTA usam o BASE_URL do servidor em execução — o mesmo conteúdo serve dev e produção.
  • Compatibilidade é contrato. O firmware recusa manifest OTA abaixo do próprio nível de API e apps declaram o api mínimo que exigem. O hub valida os dois lados no publish.
  • Ajuda sem acentos, wiki com. O app Ajuda do dispositivo lê texto puro sem acentuação (a fonte do device não tem glifos acentuados); esta wiki é web e escreve português completo.
